Demystifying IL2CPP & Unity Modding: Reversing C# Binaries with MelonLoader

Exploring runtime assembly patching, Harmony method prefix/postfix hooks, and reverse engineering IL2CPP games.

July 28, 2026

Topic

Game Modding & Reversing

Stack

  • C#
  • Unity
  • IL2CPP
  • MelonLoader
  • Harmony

When Unity compiles a game using the IL2CPP backend, the C# Intermediate Language (IL) is converted directly into C++ and compiled into native machine code. Unlike standard Mono builds where Assembly-CSharp.dll can be dropped into dnSpy or ILSpy for instant decompilation, IL2CPP strips all IL metadata from executable binaries.

However, Unity’s runtime still requires type metadata for reflection, serialization, and garbage collection. This metadata is packed into global-metadata.dat.

1. Reconstructing Assemblies with Il2CppDumper

By pairing the game’s GameAssembly.dll (or native shared object on Linux/Android) with global-metadata.dat, tools like Il2CppDumper reconstruct "dummy" .NET DLLs. These assemblies contain method signatures, class layouts, and field offsets without method implementations, giving developers a complete map of the game’s inner engine.

2. Runtime Hooking with MelonLoader & Harmony

MelonLoader bootstraps a managed .NET runtime inside the native IL2CPP process. From there, we leverage Harmony to patch compiled native methods at runtime:

[HarmonyPatch(typeof(Tower), nameof(Tower.Initialise))]
public static class TowerInitPatch
{
    [HarmonyPostfix]
    public static void Postfix(Tower __instance)
    {
        if (__instance.towerModel.name.Contains("BananaFarmer"))
        {
            __instance.range *= 1.5f;
            MelonLogger.Msg("Upgraded Banana Farmer range via Harmony hook!");
        }
    }
}

Through prefix hooks (cancelling or altering parameters before execution), postfix hooks (reading or modifying returned values), and transpilers (editing the underlying IL instructions), developers can add new gameplay systems, custom UI, and balance overhauls to existing commercial titles.

Key Takeaways

Modding commercial Unity games offers an unmatched masterclass in game architecture. You get to see how AAA and indie studios handle state management, serialization, and network sync—and build on top of them.
